# Analytical Outputs Directory

This directory stores reproducible artifacts generated by the forensic analytics pipeline:

- `monthly_performance_reconstruction.csv`: Reconstructed month-by-month financial and operational metrics.
- `forensic_investigation_summary.csv`: Audit results of the 7 data forensic issues (duplicate payments, attribution errors, timezone shifts, telephony mappings, agent identity, portfolio mix, denominator manipulation).
- `driver_analysis_13_dimensions.csv`: Quantitative decomposition across the 13 required business dimensions.
- `counterfactual_estimates.csv`: Difference-in-differences and propensity-weighted estimates of mid-year targeting strategy shift.
- `investment_model_scenarios.csv`: ₹10 Cr capital allocation financial model across 6 strategic options (Conservative, Base, Upside, Downside).
- `data_quality_issues_log.csv`: Lineage log of all quarantined, deduplicated, and normalized records.
